# Электронная кинетика аргонового ВЧИ-разряда и PINN

Материалы к предзащите НИР 3. Здесь собраны данные и скрипт для проверки предварительных результатов собственного численного решателя и прототипа PINN.

## Как проверить результаты

Из корня репозитория выполните `python3 check_results.py`. Достаточно Python 3.8 или новее и стандартной библиотеки.

1. Скрипт читает усредненные за период радиальные профили концентрации для расчетов с магнитным поворотом электронов и без него. При целевой поглощенной мощности 500 Вт и частоте 13 МГц для каждого давления он нормирует каждый профиль на собственный максимум в интервале 0,2–0,85 радиуса камеры и вычисляет максимальное расстояние между профилями в процентных пунктах.
2. Для двух отложенных режимов при давлении 1 Торр скрипт выводит сохраненные ошибки концентрации и время расчета. Для PINN указано среднее время прямого прохода после прогрева на подготовленных данных. Для численного решателя указано время получения периодического режима.
3. Последний столбец показывает отношение нормированной невязки источника ионизации у сети, обученной только по данным, к невязке у PINN. Обе оценки взяты из соответствующих запусков. Конфигурации обучения различались также шагом обучения и обработкой энергетического хвоста.

## Данные

- `data/density_profiles.json` - радиальные координаты, концентрации с магнитным членом и без него и сохраненная метрика для трёх давлений.
- `data/pinn_eval.json` - результаты оценки прототипа PINN, включая сравнение с интерполяцией.
- `data/data_only_eval.json` - результаты оценки сети, обученной по данным.

Скрипт обрабатывает сохраненные результаты. Обучение сети и генерация кинетических эталонов выполнялись отдельно и не представлены в открытом репозитория до защиты проекта.
